# GEI Use Case Specifications STR V1.1

## CASO DE USO: UC-STR-01 · Registrar una temporada

- **Estado:** ACTIVE V1.1
- **Actor:** actor V1.1 autorizado por rol y alcance; ACT-UNAUTHENTICATED only for authentication entry points.
- **Precondición:** fuentes V1.1 vigentes y autorización default DENY.
- **Flujo básico:** validar entrada; evaluar autoridad; ejecutar la intención; persistir atómicamente; auditar cuando corresponda; devolver el estado confirmado.
- **Alternativas:** validación o autoridad fallida no cambia estado; conflicto concurrente conserva trabajo; referencias retiradas no se evalúan.
- **Postcondición:** resultado coherente con Product Truth V1.1.
- **Requirement:** requisito V1.1 vigente del dominio STR.
